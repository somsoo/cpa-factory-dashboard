# UI/UX Standards (OnePage Factory)

1. **메인 컨테이너**: 가독성을 위해 max-w-md 대신 max-w-3xl 등 시원한 여백을 사용합니다.
2. **디자인 시스템**: Tailwind CSS를 기본으로 사용하며, 트렌디한 Glassmorphism (반투명 글래스) 효과를 적용합니다.
3. **광고 배치**: 구글 애드센스(Google AdSense) 등 광고 영역은 레이아웃을 해치지 않는 선에서 우아하고 자연스럽게 배치합니다.
4. **이중 패딩 금지**: 불필요한 이중 여백으로 인해 모바일 환경에서 텍스트가 찌그러지는 현상을 방지합니다.
