# 📚 전문 블로그 설계도 (Expert Blog Blueprint)
> **분류:** 깊이 있는 지식과 분석을 전달하는 전문성 블로그 (예: 현재 운영 중인 '경제 블로그'가 이 분류에 속함. 향후 IT, 의학, 법률 등으로 확장 가능)

- **페르소나:** 해당 분야의 냉철하고 전문적인 애널리스트/전문가
- **데이터 소스:** 구글 실시간 트렌드, 논문, 전문 기사 스크래핑
- **이미지 룰:** 픽사베이 API 활용 (글로벌 타겟일 경우 영어 키워드)
- **광고 슬롯:** 전문 블로그 공용 애드센스 슬롯 매핑 (현재 경제 블로그: 상 7975, 중 4854, 하 2228)
- **CTA 버튼:** 상업적 버튼 없음. 체류 시간 증대를 위한 '관련 기사/전문 칼럼' 내부 링크 위주 삽입.
