# 🎯 CPA 블로그 설계도 (CPA Auto Blueprint)

## 1. 페르소나 및 데이터
- **페르소나:** 친절한 30대 라이프스타일 에디터 (자연스러운 한국어, 정보성 어조)
- **데이터 소스:** 로컬 campaigns.json에서 광고 캠페인 정보(링크, 혜택 등)를 읽어와 포스팅.

## 2. 하이브리드 3단계 AI 글 작성 아키텍처 (Hybrid 3-Pass)
AI의 환각을 줄이고 'SEO 방어'와 'CPA 전환율 극대화'를 동시에 달성하기 위해 **하이브리드 3-Pass** 프롬프트를 거칩니다.
1. **Pass 1 (Pain Point 공감 초안):** 무조건적인 공포감이 아닌, 검색자의 고민(Pain Point)에 깊이 공감하고 유용한 정보를 제공하여 SEO 봇이 선호하는 정보성 글 작성.
2. **Pass 2 (해결책 빌드업 검토):** CPA 상품이 억지스러운 광고가 아니라 고민을 해결할 '현명하고 똑똑한 대안'으로 자연스럽게 소개되었는지 스스로 검토.
3. **Pass 3 (넛지형 CTA 리라이팅):** 글 전체의 '깔끔한 정보성' 톤앤매너를 유지하되, **버튼이 들어가는 3곳의 바로 앞 문장만큼은** 독자가 참지 못하고 클릭하도록 강력한 설득형 행동 촉구(CTA) 문장으로 반전시켜 리라이팅.

## 3. 수익화 및 CTA 배치
- **애드센스 (수동 광고):** CPA 블로그 레이아웃 전용 애드센스 슬롯(상: 2231432699, 중: 5979234123, 하: 2249871234)을 고정 사용하여 수익 최적화.
- **CTA 버튼 (Call to Action):** 시선을 끄는 강력한 색상(#ff5722)의 클릭 유도 버튼을 서론과 결론 부근에 각각 1개씩 총 2개 배치. (예: '무료 상담 신청하기').

## 4. 시각적 요소 (이미지 룰)
- **상단 썸네일 (OG 이미지):** 글 상단에 배치되는 텍스트 카드형 썸네일을 Python으로 직접 그려서 삽입. 이 이미지는 YAML Frontmatter의 image: 속성에 연결되어 카톡 공유 시 썸네일로 작동.
- **Vibe 픽사베이 이미지 (본문):** 키워드를 영어 감성 키워드로 번역하여 픽사베이에서 리얼 스톡 사진을 가져와 본문 중간에 1장 삽입. (정보글의 신뢰도 상승 목적).

## 5. UI/UX 구성
- **메뉴 구성:** 특정 CPA 캠페인 전환율 극대화를 위해 불필요한 이탈을 막는 원페이지(One-page) 스타일 심플 레이아웃 사용.

## 6. GitHub Actions 자동화 파이프라인
- **클라우드 스케줄러:** 로컬 PC가 꺼져 있어도 각 CPA 블로그의 .github/workflows/main.yml에 설정된 크론(Cron) 스케줄에 따라 서버가 자동으로 깨어나 포스팅을 발행.
- **분산 발행(Staggering):** 15개 이상의 블로그가 동시에 제미나이 API를 호출하여 한도 초과(429 Error)가 발생하는 것을 막기 위해, 각 블로그의 동작 시간은 5분~10분 단위로 다르게 분산(Offset) 설정되어 있음.
