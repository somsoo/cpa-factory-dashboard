# 🧵 쓰레드 자동 포스팅 설계도 (Threads Auto Blueprint)

Threads_Auto 프로젝트를 분석하여 추출한 인스타그램 쓰레드(Threads) 자동화 및 수익화(쿠팡 파트너스) 마스터 규칙입니다. 이 규칙은 알고리즘 섀도우밴(Shadowban)을 피하고 계정을 안전하게 성장시키는 데 필수적입니다.

## 1. 2단 분리 제휴 마케팅 전략 (가장 중요)
- **메인 본문:** 절대 쿠팡 링크나 '사주세요, 추천합니다' 같은 노골적인 상업성 멘트를 넣지 않습니다. 진짜 친구에게 일상이나 꿀팁을 공유하듯 100% 사람처럼 자연스러운 어투로 작성합니다.
- **첫 번째 답글(Reply):** 본문에 어그로(관심)가 끌린 유저를 위해, 첫 번째 답글에만 쿠팡 파트너스 링크와 상세 설명을 삽입합니다. 쓰레드의 자체 URL 미리보기(OG) 기능을 활용해 자연스럽게 상품이 노출되게 합니다.

## 2. 계정 보호 및 페이스(Pacing) 조절
- **발행 한도:** 봇(Bot)으로 정지당하는 것을 막기 위해 각 계정은 하루 최대 **12개**의 글만 작성합니다 (약 2시간 간격).
- **광고 비율(Affiliate Ratio):** database.json에 설정된 비율을 철저히 지킵니다. (예: 비율이 2라면, 일반 일상글 2개 발행 후 광고글 1개 발행).
- **영구 차단 주제:** 정치, 젠더, 종교, 혐오, 사회적 논란, 특정 연예인 비하 등 민감한 주제는 프롬프트 단계에서 원천 차단(Safety 필터)합니다.

## 3. 무중단 시스템 아키텍처
- **API 로테이션:** 제미나이 429 에러(한도 초과) 발생 시 스크립트를 죽이지 않고, 즉시 3.7 -> 3.6 -> 3.5 -> 3.1 순으로 모델 및 API 키를 스위칭하여 끊김 없이 타격합니다.
- **DB Less:** 별도의 외부 데이터베이스 없이 깃허브 레포지토리 내의 database.json을 DB처럼 활용하여 발행 카운트와 상태를 저장합니다.
- **크론 탭:** 30분 간격 GitHub Actions 동작.
