# 🧮 유틸리티 웹앱 설계도 (Utility App Blueprint)

과거 성공적으로 구축한 '원더윅스 계산기(Wonder Weeks)' 및 유사 유틸리티 사이트(세금 계산기, 스도쿠 등)를 복제하여 새로운 주제의 웹앱을 만들 때 지켜야 할 **표준 체크리스트 및 규칙**입니다.

## 1. 프로젝트 개요 및 기술 스택
- **유형**: 단일 페이지 애플리케이션(SPA) 스타일의 메인 계산기 + 롱테일 키워드 유입을 위한 정적 서브(가이드) 페이지.
- **기술 스택**: 순수 HTML5, CSS3, Vanilla JavaScript (React 등 무거운 프레임워크 배제, 극강의 로딩 속도 최우선).
- **배포 방식**: GitHub Pages를 이용한 정적 호스팅 및 커스텀 도메인 연결.

## 2. 레이아웃 및 디자인 (UI/UX)
- **모바일 퍼스트**: 전체 컨테이너를 `max-width: 600px` 또는 `768px`로 제한하여 모바일 앱처럼 보이게 최적화.
- **폰트**: 가독성이 뛰어난 웹 폰트(주로 `Pretendard`) 적용.
- **사용자 흐름(Flow)**:
  1. 메인 페이지에서 조건(날짜, 금액 등) 입력.
  2. JavaScript가 브라우저 단에서 즉시 계산하여 동적 결과(타임라인, 표 등) 노출.
  3. 결과 내 특정 단계를 클릭하면 상세 설명을 담은 정적 '서브 페이지(예: `/guides/`)'로 이동.

## 3. 수익화 모델 배치 전략 (Ads & Affiliate)
무분별한 '구글 자동 광고'는 웹앱의 레이아웃과 UI를 파괴하므로 **전면 금지**합니다. 철저하게 계산된 명당자리에 수동으로 광고를 삽입합니다.

- **구글 애드센스 (수동 반응형, `data-full-width-responsive="true"`)**:
  - **메인 페이지 1**: 계산 '결과 박스' 바로 아래 (가장 시선이 오래 머무는 명당).
  - **메인 페이지 2**: 페이지 맨 하단 (스크롤을 끝까지 내린 유저 대상).
  - **서브 페이지**: 본문을 다 읽은 후 하단부, 혹은 쿠팡 파트너스 추천 박스 바로 위.
- **쿠팡 파트너스 (제휴 마케팅)**:
  - 정보 제공(서브 페이지)의 문맥에 맞는 타겟팅 상품 추천.
  - 본문 하단에 배경색이 들어간 박스 형태로 삽입.
  - 공정위 대가성 문구 반드시 삽입.

## 4. 테크니컬 SEO 필수 체크리스트 (가장 중요)
블로그처럼 자동화된 프레임워크(Jekyll 등)를 쓰지 않는 순수 HTML 구조이므로, AI가 아래 항목들을 빠짐없이 직접 코딩하고 파일로 생성해야 합니다.

- [ ] **메타 태그 세팅 (`<head>`)**:
  - `title`, `meta description` 
  - `canonical` 태그 (중복 문서 방지)
- [ ] **오픈그래프 (OG) 이미지 및 태그**:
  - `og:title`, `og:description`, `og:url` 삽입.
  - 800x800 등의 사이즈로 텍스트가 적힌 썸네일 카드를 이미지 파일(`og-image.png`)로 루트에 생성 및 태그(`og:image`) 연결.
- [ ] **파비콘 (Favicon & PWA Icon)**:
  - 브라우저 탭을 위한 `favicon.ico` 루트 저장 및 `<link rel="icon">` 삽입.
  - 모바일 홈 화면 추가를 위한 `icon.png` 제작 및 PWA 매니페스트 연결.
- [ ] **사이트맵 (`sitemap.xml`)**:
  - 루트 URL 및 모든 정적 서브 페이지(`/guides/`)의 URL이 포함된 XML 파일을 직접 작성.
- [ ] **로봇 배제 표준 (`robots.txt`)**:
  - 모든 봇 허용 및 `Sitemap` 경로 명시.
- [ ] **구조화된 데이터 (JSON-LD)**:
  - `<script type="application/ld+json">` WebApplication 스키마 마크업 삽입.
  - (순수 HTML 유틸리티 사이트는 주기적으로 발행되는 '글'이 없으므로 RSS(`feed.xml`)는 생략 가능).

## 5. 생성 파이프라인 (Action Item for AI)
새로운 웹앱 제작 요청 시:
1. 기존 `WonderWeeks` 또는 `_template`의 구조(폴더, CSS, 뼈대, 광고 위치)를 스켈레톤으로 복제.
2. 새 주제에 맞게 JS 계산 로직과 HTML 작성.
3. **4번 항목의 SEO 체크리스트 물리 파일들(파비콘, OG이미지, 사이트맵)을 빠짐없이 직접 렌더링하고 HTML에 하드코딩 연결.**
